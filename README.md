# Personal Directory Homepage

Open `index.html` in a browser to view the site, or run a static server from this folder.

The homepage is a clickable file tree. Edit the `.txt` files inside each folder to make the site yours.

For the consumption map, edit `consumption/media.json`. Each item can include:

- `title`: the book, movie, album, etc.
- `type`: `book`, `film`, or `album`.
- `year`: optional.
- `cover`: an image URL or a local path like `covers/my-cover.jpg`.
- `x` and `y`: where it should sit on the scrolling map.
